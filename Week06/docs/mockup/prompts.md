## 1. Homepage Mockup

### Requirements
Header (logo, navigation links, search bar, cart icon with badge), hero banner (headline, copy, CTA button), category section (cards for food categories), and a featured dishes grid (dish cards showing title, chef, price, rating, and add button).

### Initial Prompt
```
A high-fidelity modern UI design mockup for a restaurant homepage named 'TastyHub' in Vietnamese. Top navigation bar with logo '🍔 TastyHub', search bar, navigation links (Trang chủ, Thực đơn, Đặt bàn, Liên hệ) and a cart icon with a red badge '0'. Below, a gorgeous hero banner with an inviting food headline and an orange CTA button 'Xem thực đơn'. Underneath, a section of categories cards (Khai vị, Món chính, Lẩu & Nướng, Tráng miệng, Đồ uống) with food icons and a featured dishes grid with cards showing food photos, titles, prices in VND, star ratings, and a 'Thêm vào giỏ' button. Premium layout, clean aesthetics, light mode, warm theme.
```

*Status: Approved. Saved as `homepage.png`*
